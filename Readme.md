# Beer Tuesday Bot

Телеграм-бот, который принимает фото пива из чата, отправляет его в Groq Cloud (по умолчанию модель `llama-3.2-11b-vision`) и возвращает ироничный отзыв сомелье. Groq снял с поддержки прежние vision-модели (например, `llava-v1.5-7b-4096-preview` и `llama-3.2-11b-vision-preview`), поэтому при старом значении переменной окружения бот автоматически переключится на актуальную модель из [документации по Vision](https://console.groq.com/docs/vision).

## Возможности

- Команды `/start` и `/help` объясняют, как пользоваться ботом.
- Команда `/postcard` генерирует свежую открытку-приглашение на ближайший пивной вторник.
- Команда `/barhopping` шлёт приглашение на бархоппинг с открытым опросом.
- Команда `/debug_postcards on|off` включает или выключает отладочную рассылку открыток каждые пять минут.
- Принимает фотографии (с подписью или без неё) и отправляет их в Groq Vision API.
- Возвращает короткий ироничный отзыв о присланном напитке.
- Вежливо реагирует на текстовые сообщения без фото.
- Каждый понедельник в 21:00 (по умолчанию) автоматически шлёт открытку в выбранный чат, чтобы позвать всех на "Пивной вторник" во вторник в 19:30.
- Каждый предпоследний четверг в 12:00 по Алматы напоминает о бархоппинге, который проходит в предпоследнюю пятницу месяца.

### Откуда берётся открытка

Изображение генерируется через Hugging Face Inference API с помощью модели `black-forest-labs/FLUX.1-dev`. Если API недоступно или отвечает с ошибкой оплаты, бот использует локальный файл `beer_bot/download.jpg` (или fallback-рендер на Pillow) в качестве пивной открытки. Для бархоппинга используется отдельный локальный fallback `beer_bot/postcard_placeholder.jpg`; в остальном задействуется тот же пайплайн: берётся отдельный промпт, при необходимости накладывается `negative_prompt`, а затем картинка отправляется в чат вместе с подписью и опросом.

## Еженедельные открытки

Чтобы настроить еженедельную рассылку, отправьте команду `/chatid` в нужном групповом чате (или добавьте бота и используйте `/start`).
Бот ответит числовым идентификатором — укажите его в переменной окружения `POSTCARD_CHAT_ID`, и тогда приглашение будет приходить автоматически.
Время отправки можно настроить через `POSTCARD_WEEKDAY` (0=воскресенье), `POSTCARD_HOUR` (0–23) и `POSTCARD_MINUTE` (0–59).
По умолчанию открытки улетают по понедельникам в 21:00 по таймзоне из `POSTCARD_TIMEZONE`, чтобы напомнить о пивном вторнике на следующий день.

## Ежемесячное напоминание о бархоппинге

Чтобы бот напоминал о бархоппинге, задайте `BARGHOPPING_CHAT_ID` (по умолчанию используется `POSTCARD_CHAT_ID`).
Напоминание отправляется в предпоследний четверг месяца в 12:00 по времени из `BARGHOPPING_TIMEZONE` (по умолчанию `Asia/Almaty`).
В уведомлении используется отдельный промпт, подпись и текст опроса, которые можно переопределить переменными окружения.

## Быстрый старт

1. **Создайте бота у @BotFather** и получите токен.
2. **Получите API-ключ Groq Cloud** на [console.groq.com](https://console.groq.com/) и убедитесь, что у вас есть доступ к модели `llama-3.2-11b-vision` (или более свежей из [vision-документации](https://console.groq.com/docs/vision)). Если в конфигурации остались устаревшие `llava-v1.5-7b-4096-preview` или `llama-3.2-11b-vision-preview`, удалите их из `GROQ_MODEL` или замените на актуальную модель.
3. Скопируйте `.env.example` в `.env` и заполните значения:
   ```bash
   cp .env.example .env
   ```
4. Установите зависимости (включая поддержку планировщика задач для еженедельных уведомлений) и запустите бота:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   python -m beer_bot.main
   ```
5. Добавьте бота в дружеский чат и отправьте ему фото.

## Деплой на Railway

1. Установите [Railway CLI](https://docs.railway.com/develop/cli) и выполните `railway login`.
2. Создайте новый проект и подключите репозиторий (`railway init`).
3. Railway автоматически подхватит `requirements.txt` и `railway.json`.
4. Задайте переменные окружения через `railway variables set` или в веб-интерфейсе:
   - `TELEGRAM_BOT_TOKEN`
   - `GROQ_API_KEY`
   - (опционально) `GROQ_MODEL`, `GROQ_BASE_URL`, `GROQ_TEMPERATURE`, `GROQ_MAX_TOKENS`
   - (для открыток) `HUGGINGFACE_API_TOKEN`, `POSTCARD_CHAT_ID`, `POSTCARD_WEEKDAY`, `POSTCARD_HOUR`, `POSTCARD_MINUTE`, `POSTCARD_TIMEZONE`
5. Запустите деплой командой `railway up` или через кнопку Deploy в панели управления.

При старте Railway выполнит `python -m beer_bot.main`, и бот начнёт опрашивать Telegram.

## Переменные окружения

| Переменная | Описание |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен бота из @BotFather. |
| `GROQ_API_KEY` | API ключ Groq Cloud. |
| `GROQ_MODEL` | (Опционально) Название модели Groq, по умолчанию `llama-3.2-11b-vision`. Устаревшие значения автоматически заменяются на актуальное по умолчанию. |
| `GROQ_BASE_URL` | (Опционально) URL эндпоинта Chat Completions. |
| `GROQ_TEMPERATURE` | (Опционально) Температура сэмплинга ответа. |
| `GROQ_MAX_TOKENS` | (Опционально) Максимальное число токенов в ответе. |
| `HUGGINGFACE_API_TOKEN` | Токен доступа Hugging Face для генерации открыток. |
| `HUGGINGFACE_MODEL` | (Опционально) Модель для открыток, по умолчанию `black-forest-labs/FLUX.1-dev`. |
| `HUGGINGFACE_BASE_URL` | (Опционально) Полный URL эндпоинта Serverless Inference, если нужно переопределить. |
| `POSTCARD_CHAT_ID` | ID чата, куда автоматически отправляется приглашение. |
| `POSTCARD_WEEKDAY` | (Опционально) День недели рассылки, `0`=воскресенье ... `6`=суббота. По умолчанию `1` (понедельник). |
| `POSTCARD_HOUR` | (Опционально) Час отправки открытки (0–23). По умолчанию `21`. |
| `POSTCARD_MINUTE` | (Опционально) Минуты отправки открытки (0–59). По умолчанию `0`. |
| `POSTCARD_PROMPT` | (Опционально) Кастомное текстовое описание открытки. |
| `POSTCARD_NEGATIVE_PROMPT` | (Опционально) Нежелательные элементы для генерации открытки. |
| `POSTCARD_CAPTION` | (Опционально) Подпись к открытке. |
| `POSTCARD_TIMEZONE` | (Опционально) Таймзона для расписания, по умолчанию `Asia/Almaty`. |
| `BARGHOPPING_CHAT_ID` | (Опционально) ID чата для напоминаний о бархоппинге, по умолчанию `POSTCARD_CHAT_ID`. |
| `BARGHOPPING_PROMPT` | (Опционально) Описание открытки для бархоппинга. |
| `BARGHOPPING_NEGATIVE_PROMPT` | (Опционально) Нежелательные элементы при генерации открытки для бархоппинга. |
| `BARGHOPPING_CAPTION` | (Опционально) Подпись к открытке для бархоппинга. |
| `BARGHOPPING_TIMEZONE` | (Опционально) Таймзона напоминания о бархоппинге, по умолчанию `Asia/Almaty`. |
| `BARGHOPPING_HOUR` | (Опционально) Час отправки напоминания (0–23), по умолчанию `12`. |
| `BARGHOPPING_MINUTE` | (Опционально) Минуты отправки напоминания (0–59), по умолчанию `0`. |
| `BARGHOPPING_POLL_QUESTION` | (Опционально) Текст опроса о бархоппинге. |

## Структура проекта

```
beer_bot/
├── __init__.py
├── config.py         # чтение переменных окружения
├── groq_client.py    # обёртка над Groq Vision API
├── handlers.py       # обработчики Telegram-сообщений
├── main.py           # точка входа бота
└── postcard_client.py # генерация открыток через Hugging Face
```

## Разработка

- Для авто-подгрузки переменных из `.env` используется `python-dotenv`.
- Логирование настроено на уровень `INFO`. При ошибках обращения к Groq бот отправляет дружелюбное сообщение в чат и пишет стек в логи.
